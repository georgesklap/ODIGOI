# ΟΔΗΓΟΙ — εφαρμογή κινητού (μόνο προβολή)

Εφαρμογή PWA για Android και iPhone, ανεξάρτητη από την εφαρμογή ΑΞΥΠ. Εμφανίζει άδειες, βάρδιες,
νυχτερινά/πενθήμερα και οφειλόμενα ρεπό των οδηγών, όπως τα δημοσιεύει το κουμπί **ΔΗΜΟΣΙΕΥΣΗ** του ODIGOI.xlsm.

* Τα υπηρεσιακά δεδομένα βρίσκονται ΜΟΝΟ κρυπτογραφημένα στο `data/odigoi.json`
  (μορφή `odigoi-enc-1`: PBKDF2-SHA256 600.000 επαναλήψεις → AES-256-CBC + HMAC-SHA256).
* Ο κωδικός ή κάποιο κλειδί δεν υπάρχει πουθενά σε αυτό το repository.
* Η εφαρμογή δεν υπολογίζει τίποτα: εμφανίζει τις τιμές του Excel.
* Το `manifest.webmanifest` με `"name": "ΟΔΗΓΟΙ"` είναι και ο έλεγχος ασφαλείας της δημοσίευσης:
  το odigoi_publish.ps1 αρνείται να ανεβάσει δεδομένα σε repository που δεν το έχει.

Αρχεία: `index.html`, `app.js`, `style.css`, `manifest.webmanifest`, `sw.js`, `icons/`.
Το `data/odigoi.json` δημιουργείται και ενημερώνεται αποκλειστικά από τη ΔΗΜΟΣΙΕΥΣΗ.
